# Delta-TFT — Data analysis bootstrap

Quick notes to get started with the provided `requirements.txt`.

Setup (recommended):

1. Create and activate a virtual environment:

   python -m venv .venv
   .venv\Scripts\activate

2. Install dependencies:

   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

3. Start JupyterLab:

   jupyter lab

Suggestions:
- Use `pandas`, `numpy`, `scipy`, and `statsmodels` for statistical workflows.
- Add or pin package versions as needed for reproducibility.
